## 2. Logic Chain

1. **ISO 8601 String Comparison Normalization**:
   Wrapping `processed_at` and `created_at` in `datetime(...)` forces SQLite to parse the input ISO 8601 timestamp string (`'2026-07-21T05:00:00.000Z'`) into a normalized SQLite datetime object before comparing with `datetime('now', '-7 days')`. This resolves the ASCII `'T'` (84) vs space `' '` (32) comparison bug.

2. **TTL Precedence Guard**:
   Structuring the `idempotency_keys` deletion condition as `(expires_at IS NULL AND datetime(processed_at) < datetime('now', '-7 days')) OR (expires_at IS NOT NULL AND expires_at < unixepoch('now'))` ensures that keys with explicit custom TTLs (`expires_at IS NOT NULL`) are deleted ONLY when `expires_at < unixepoch('now')`. Keys without custom TTL (`expires_at IS NULL`) fall back to the 7-day default retention window.

3. **Complete Table Retention Coverage**:
   Adding `DELETE FROM checkout_idempotency WHERE expires_at < unixepoch('now')` prevents the `checkout_idempotency` table from accumulating stale rows over time.

4. **Independent Catch Isolation**:
   Each `db.run()` call retains its own `.catch()` handler, ensuring partial DB query rejections do not block subsequent deletion steps.
